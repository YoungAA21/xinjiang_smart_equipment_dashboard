# 设备报告

报告聚焦采集侧振动、温度、负压 / 压力，去掉 IO 选择、去抖和状态统计。不查询声纹、录音或声学诊断。

## 页面与操作

- `/#/reports`「设备报告」统一承载配置、查询、查看、保存和下载。导航只保留一个设备报告入口。旧地址 `/#/reports/view` 重定向到此页，保留 query 和 hash，已有存档链接继续可用。
- 页头“报告配置”在当前页展开设置：关注指标、采集模块、默认对比方式及固定班次规则。首次展开时加载目录，仅显示数据位置的初次加载态；收起保留草稿。修改但未保存时显示状态并禁用查询，保存后取消旧请求并使结果待重新查询，不自动发起查询或生成报告。
- 主区域选择日期、班报 / 日报和班次，点击“查询报告”时才读取接口。切换条件只取消尚未完成的请求；查询期间或失败后保留旧结果，条件或范围与结果不一致时显示状态并禁用保存、下载。
- 查询成功后展示本期测点汇总、加权均值、极值、末值、样本数、缺失时间桶及对比结果，点击“时间桶明细”弹窗查看 5 分钟趋势和明细表；弹窗支持关闭按钮、右上角关闭及 Esc，关闭后保留原列表，展开完整 HTML 报告。
- “保存报告”将当前查询结果写入本机存档，同周期再次保存替换原快照；“下载 HTML”无需先保存。查询本身不写存档，存储空间不足不阻断查询和下载；保存失败明确提示。
- “已存报告”直接读取固定 HTML，不请求接口；旧报告继续可读。已有存档周期点击“查询报告”仍按当前规则重新读取接口，原存档保持到用户再次保存。只带无效存档链接时提示未找到，不自动生成。
- 配置与最近 60 份报告按登录用户保存在当前浏览器，只保存 HTML 和元数据，不保存原始历史数组。无后台定时生成或跨浏览器共享存档。HTML 自带样式和 SVG 趋势，可离线打开和通过浏览器打印。

## 数据与边界

仅复用 `/api/configuration/modules`、`/api/configuration/modules/{moduleId}/points?includeLatest=false`、`/api/telemetry/history/aggregate-stored`、`/api/analysis/alarms` 和 `/api/analysis/trend-alarms`，继续经过现有采集侧同源代理，不携带声学登录令牌；使用既有 `/_telemetry-api/` 前缀，无需为此接口修改 Nginx。

历史固定 `bucketMinutes=5&limit=200`，每次最多覆盖 200 个时间桶；自然日的 288 桶分两段无重叠读取，白班 102 桶、夜班 96 桶均为一次查询，事件每周期最多 1000 条；达到上限显示可能截断。并发上限为 4。离开页面、切换周期或范围、取消生成会中止请求；过期结果不写入页面或快照。全部测点历史请求失败时不固化失败报告，可稍后重试。部分失败、缺数、无效采样及模块目录失败均明确提示。

## 时间与统计

早班 09:30–18:00，晚班 18:00–次日 02:00，晚班归属开始日期；只接受已结束周期。默认最近已结束班次，日报默认昨日自然日。班报可与相邻上一班或前一日同班次比较，日报与前一自然日比较。区间为 `[开始, 结束)`，接口时间使用浏览器本地时间，现场应使用 Asia/Shanghai 时区。

验证返回的测点身份和 5 分钟时间桶边界。仅使用质量 Good（数字 1 或字符串 Good）、sampleCount 为正整数且统计数值有效的桶；0 和负数有效，缺失桶不补零。同时间重复且统计一致的桶去重，冲突重复拒绝处理。均值为 Σ(averageValue × sampleCount) / ΣsampleCount；极值取 minValue / maxValue，末值取最后有效桶 lastValue。趋势直接使用各桶平均值，缺数处断开，不推算原始样本分位数、标准差或精确越限持续时间。

只有两周期均有有效采样、有效时间桶占比均达到 60% 且未截断才比较均值。变化率为 `(本期 − 对比期) / abs(对比期)`，基数为零时仅给绝对差。负压升降不直接判断好坏，均值变化绝对值达到 10% 仅提示交班复核。越限、缺数及查询问题同时列为复核项。有效时间桶占比不是设备在线率。

桶极值越限使用生成时当前阈值复核，不能当作报警次数或持续时间，不替代历史阈值或正式告警。硬限值与趋势新发事件分别统计，限于区间内开始且可唯一匹配所选测点的事件，不推断跨期持续报警、在线率、停机时长或产量。
