# 设备报告配置与查看

报告聚焦采集侧振动、温度、负压 / 压力，去掉 IO 选择、去抖和状态统计。不查询声纹、录音或声学诊断。

## 页面与操作

- `/#/reports` 为「报告配置」：选择三类重点指标与采集模块，保存配置；选择已结束的班次或自然日，生成并保存 HTML 报告。同周期重新生成会替换当前用户的本机快照。
- `/#/reports/view` 为「报告查看」：默认打开最近已结束的上一班，可按日期、班次、班报 / 日报或已存报告切换。首次查看未存档周期时按已保存配置汇总并保存，已有快照不再查询实时数据；查看页不提供生成参数或重新生成操作。
- 报告包含交班摘要，按振动、温度、负压 / 压力分组的均值、最小 / 最大值、对比均值、变化与趋势，以及告警概况、数据问题。HTML 自带样式和 SVG 趋势，无外部依赖，可离线打开和通过浏览器打印。
- 配置和最近保存的 60 份报告按登录用户保存在当前浏览器。只保存 HTML 与周期、范围等元数据，不保存原始历史数组。存储失败明确提示，不显示保存成功。未接入后台定时生成或跨浏览器共享存档。

## 数据与边界

仅复用 `/api/configuration/modules`、`/api/configuration/modules/{moduleId}/points?includeLatest=false`、`/api/telemetry/history`、`/api/analysis/alarms` 和 `/api/analysis/trend-alarms`，继续经过现有采集侧同源代理，不携带声学登录令牌；未新增接口或拓宽代理。

历史每参数每周期最多 100000 条，事件每周期最多 1000 条；达到上限显示可能截断。并发上限为 4。离开页面、切换周期或范围、取消生成会中止请求；过期结果不写入页面或快照。全部测点历史请求失败时不固化失败报告，可稍后重试。部分失败、缺数、无效采样及模块目录失败均明确提示。

## 时间与统计

早班 09:30–18:00，晚班 18:00–次日 02:00，晚班归属开始日期；只接受已结束周期。默认最近已结束班次，日报默认昨日自然日。班报固定与相邻上一班比较，日报与前一自然日比较。区间为 `[开始, 结束)`，接口时间使用浏览器本地时间，现场应使用 Asia/Shanghai 时区。

验证返回的测点身份，去除区间外样本，按采集时间去重。只使用质量明确为 Good 的有限数值，0 和负数有效；未知质量、null 不当成零。均值及极值来自原始有效样本。趋势按分钟中位值、尾随 5 分钟中值和 EMA（α=0.3）处理，缺失分钟断开并重置。

只有两周期均有有效采样、有数分钟占比均达到 60% 且未截断才比较均值。变化率为 `(本期 − 对比期) / abs(对比期)`，基数为零时仅给绝对差。负压升降不直接判断好坏，均值变化绝对值达到 10% 仅提示交班复核。越限、缺数及查询问题同时列为复核项。有数分钟占比不是设备在线率。

采样越限使用生成时当前阈值重算，不替代历史阈值或正式告警。硬限值与趋势新发事件分别统计，限于区间内开始且可唯一匹配所选测点的事件，不推断跨期持续报警、在线率、停机时长或产量。
